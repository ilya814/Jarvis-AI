# 🤖 JARVIS — Free AI Assistant

A sleek, Jarvis-style AI chat interface you can host for free on GitHub Pages.

![JARVIS Screenshot](https://i.imgur.com/placeholder.png)

## ✨ Features

- 💬 Chat with a powerful AI (Llama 3.3 70B)
- 🌍 Switch response language (14+ languages)
- 🔗 Paste links for the AI to analyze
- 🐍 Coding help, writing, translation, and more
- ⚡ Fast responses via Groq
- 🆓 Completely free to use and host


> 💡 **Tip:** Your API key is never stored — it only lives in your browser tab.

## 🛠 Customization

- **Language:** Change the response language from the dropdown
- **Model:** Choose between speed and power
  - `Llama 3.3 70B` — Best quality
  - `Llama 3.1 8B` — Fastest responses
  - `Mixtral 8x7B` — Great for coding
